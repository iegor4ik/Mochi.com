# 🍡 M-o-chi.com

Полноценный форум с нуля: темы, категории, личные чаты с фото, лайки, уведомления,
роли, жалобы, баны, **посты в профиле с rich-редактором**, **подписки**, **лента**
и **конструктор тем оформления** с возможностью делиться своими темами.

Логотип построен вокруг выделенной буквы **O** — градиентного «моти-шара», который
задает визуальный стиль всего форума (скругления, градиенты, плавные анимации).

## 📜 Посты профиля

Создаются из профиля (`✍️ Создать пост`) или ленты. Обязательное поле одно — **название**;
обложка, теги и содержимое — по желанию. Редактор (contenteditable):

- **B / I / U / S**, заголовки H1–H3, очистка форматирования;
- **размер текста** (Мелкий … Огромный) и **шрифт** (веб-безопасные + загруженные);
- **загрузка своих шрифтов** TTF/OTF/WOFF/WOFF2 (до 10 МБ) — применяются через `@font-face`;
- **фото в любую точку** текста (вставка в позицию курсора, сколько угодно);
- выравнивание; содержимое сохраняется после строгой allowlist-санитизации на сервере.

**Видимость:**

| Режим | Кто видит |
|---|---|
| 🌐 Публичный | Общая лента + профиль + поиск (в т.ч. по `#тегам`) |
| 👤 Личный | Только в профиле автора (не в ленте и не в поиске) |
| 🔒 Приватный | Только по прямой ссылке `#/post/<id>` |

**Тема-обсуждение:** комментировать пост нельзя. Автор может один раз нажать
«💬 Создать тему обсуждения» — появится форумная тема с названием
`Тема: <название поста>` и ссылкой на пост.

## 🚀 Быстрый старт

### Требования
- Node.js ≥ 18
- Docker Desktop (для PostgreSQL)

### 1. Запуск базы данных

```bash
docker compose up -d db
```

> Порт проброшен как **5433** (чтобы не конфликтовать с системным PostgreSQL).
> Если 5433 занят — поменяйте маппинг в `docker-compose.yml` и `DATABASE_URL`.

### 2. Установка и запуск сервера

```bash
cd server
npm install
cp .env.example .env        # при необходимости поправьте DATABASE_URL
npm run migrate             # применит SQL-миграции из db/migrations
npm run seed                # наполнит демо-данными (флаг --force — пересев)
npm start                   # http://localhost:3000
```

Готово! Откройте **http://localhost:3000**

### Альтернатива: всё в Docker

```bash
docker compose up -d --build
```
Приложение поднимется на http://localhost:3000 вместе с БД.

    │   ├── config/db.js    # пул pg + транзакции
    │   ├── middleware/     # auth (JWT+бан), validate, upload (multer: фото+шрифты)
    │   ├── routes/         # auth, users(+follow), categories, topics, posts,
    │   │                   # chat(+dm_policy), notifications, reports, search(#теги),
    │   │                   # admin, upload(+font), user-posts, feed
    │   └── utils/          # helpers.js, post-utils.js (санитайзер HTML)

### Схема БД (основное)

`users` (+`dm_policy`) · `categories` · `topics` · `posts` (с `parent_post_id` для ответов) ·
`user_posts` (rich-контент JSONB, видимость, теги, обложка, `topic_id`) · `follows` ·
`likes` · `conversations` · `messages` · `notifications` · `reports` · `bans` ·
`schema_migrations` (журнал миграций).

## 🔌 API (кратко)

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/register` `/login` | регистрация / вход |
| GET | `/api/auth/me` | текущий юзер + счётчики |
| GET | `/api/categories` | категории со счётчиками |
| CRUD | `/api/categories/:id` | управление (admin) |
| GET/POST | `/api/topics` | лента тем (фильтры, сортировки, пагинация) |
| GET | `/api/topics/:id` `/api/topics/:id/posts` | тема и её посты |
| POST | `/api/topics/:id/posts` | ответ (текст + фото) |
| PATCH/DELETE | `/api/posts/:id` | правка / мягкое удаление |
| POST | `/api/posts/:id/like` | лайк-тоггл |
| GET/POST/PATCH/DELETE | `/api/user-posts…` | посты профиля (CRUD, видимость, `/:id/topic`) |
| GET | `/api/feed?tab=recent\|popular\|following` | лента постов |
| POST/DELETE | `/api/users/:u/follow` | подписка / отписка |
| GET | `/api/users/:u/followers` `/following` | списки подписок |
| PUT | `/api/users/me` | профиль, тема, `dm_policy` |
| POST | `/api/users/me/avatar` | аватар (multipart) |
| GET/POST | `/api/chat/conversations…` | диалоги и сообщения (учитывают `dm_policy`) |
| GET | `/api/notifications` `/unread-count` | уведомления |
| POST | `/api/reports`, GET/PATCH | жалобы (очередь для mod/admin) |
| GET | `/api/search?q=` | поиск (в т.ч. `#тег` → посты) |
| GET/PATCH/DELETE | `/api/admin/*` | статистика, юзеры, роли, баны |
| POST | `/api/upload` `/api/upload/font` | загрузка изображения / шрифта |

Полный список — в коде роутов (`server/src/routes/`), каждый обработчик задокументирован.

## 🎨 Конструктор тем

Настройки → «Конструктор темы»:
- режим **светлая/тёмная**;
- два акцентных цвета (градиент логотипа перекрашивается вместе с сайтом);
- радиус скруглений и масштаб шрифта;
- фоновое свечение;
- 6 готовых палитр (Моти, Матча, Сакура, Океан, Закат, Виноград);
- **Сохранить** — тема привязывается к профилю;
- **Поделиться** — ссылка вида `http://host/?theme=<base64>`;
- **Код темы** — экспорт/импорт base64-строкой.

## 🔒 Безопасность

- пароли — bcrypt (10 раундов);
- JWT (7 дней) в заголовке `Authorization`;
- параметризованные SQL-запросы (защита от инъекций);
- экранирование HTML на фронте (защита от XSS);
- **allowlist-санитайзер rich-контента постов** (теги/атрибуты/CSS-свойства/URL);
- rate-limit на авторизацию (40 запросов / 15 мин);
- ограничение размера и типа загружаемых файлов (фото ≤ 5 МБ, шрифты ≤ 10 МБ);
- helmet, CORS, скрытие `x-powered-by`;
- проверка ролей на каждом защищённом эндпоинте.
